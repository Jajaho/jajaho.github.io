How to sketch rectangles
  • Arrows or WASD draw lines between grid vertices. Each line can be drawn only once.
  • Rectangles may be completed using obstacles — the red blocked edges.
  • A rectangle scores 2n, where n is the number of connected rectangles plus one. Rectangles connect by sharing an edge, drawn or obstacle.
  • Colours: green means every edge is yours, yellow means one of yours plus obstacles, purple is mixed.
  • The game ends when no new line can be drawn from the current position — so build connected clusters while you still can.
